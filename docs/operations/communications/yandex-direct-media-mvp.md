# COMM-09 · прямая загрузка тестовых медиа

Утверждённое владельцем исключение для тестового MVP. Mini App и будущий
Capacitor отправляют PUT напрямую в Yandex Object Storage. Случайный ключ
под `mvp-media/` содержит 256 бит энтропии. Получив постоянную HTTPS-ссылку,
любой может открыть файл. Любой также может отправить PUT в этот префикс.
CORS ограничивает браузерный доступ по origin. Проверки типа и размера в
приложении действуют только на его собственные загрузки. Использовать
исключительно тестовые файлы. Dexie не передаёт файлы. Связь с сообщениями
в отдельной задаче.

## Перед согласованием облачных изменений

Репозиторий указывает на существующий бакет `mezfit-comm-poc-20261106` в
каталоге `mezfit-media`. 9 ноября 2026 года анонимный запрос ListObjectsV2
вернул HTTP 403. Для инвентаризации нужны права владельца. Доступ к текущей
Policy, ACL, CORS и перечню объектов в рабочей среде отсутствует.

Владелец выполняет следующие операции чтения в своей авторизованной сессии.
Хранить результаты локально. Не публиковать ключи объектов и credentials.

```sh
bucket=mezfit-comm-poc-20261106
endpoint=https://storage.yandexcloud.net
aws --endpoint-url "$endpoint" s3api get-bucket-policy --bucket "$bucket"
aws --endpoint-url "$endpoint" s3api get-bucket-acl --bucket "$bucket"
aws --endpoint-url "$endpoint" s3api get-bucket-cors --bucket "$bucket"
aws --endpoint-url "$endpoint" s3api get-bucket-lifecycle-configuration --bucket "$bucket"
aws --endpoint-url "$endpoint" s3api list-objects-v2 --bucket "$bucket" --query 'Contents[].Key'
aws --endpoint-url "$endpoint" s3api list-object-versions --bucket "$bucket" --prefix mvp-media/
```

Проверить также настройки публичного доступа и квоты бакета в консоли.
Отсутствие отдельной политики или CORS фиксировать по соответствующему
ответу сервиса. Если префикс занят, есть широкие публичные разрешения,
срабатывает существующий lifecycle или изоляция не подтверждается, остановиться
и согласовать другой префикс либо отдельный тестовый бакет. Репозиторий сам
ресурсы не создаёт.

## Проект изменений

[Фрагмент Policy](../../../infra/yandex-media-mvp/policy.fragment.json) даёт
только GetObject и условный PutObject на выделенный префикс. Условие
`Null: false` требует заголовок, клиент отправляет `If-None-Match: *`.
При приёмке проверить отказ PUT без заголовка и повтор с тем же ключом.
Общие настройки публичного чтения и листинга оставить выключенными.

[Правило CORS](../../../infra/yandex-media-mvp/cors.rule.json) содержит
заполнитель. Подставить точный `location.origin` действующего Mini App из
отчёта «Проверка сети без VPN». Сопоставить с существующими правилами, чтобы
более раннее правило не перехватывало preflight. Origin будущего Capacitor
добавить после проверки сборки на устройстве.

После инвентаризации подготовить итоговый diff Policy и CORS на основе
фактических правил и согласовать конкретные изменения с владельцем.
Сохранить исходные конфигурации для отката. Применение проекта из этого PR
автоматически не запускается. Облачные функции и их IAM bindings не удаляются.
Для прямой загрузки Lockbox и GitHub Variables прежнего шлюза не нужны.

## Приёмка после применения

1. На телефоне открыть Mini App, выключить VPN, перейти в диагностику
   «Проверка сети без VPN» и выбрать несекретное фото или тестовое MP4.
2. Загрузить файл и открыть ссылку. Проверить тот же URL в отдельном браузере
   без входа. Для MP4 проверить перемотку и ответ HTTP 206 на GET с Range.
3. Проверить анонимный отказ листинга, DELETE, PUT без условия и доступа к
   известному приватному объекту вне префикса. Повтор условного PUT на уже
   занятый тестовый ключ должен завершиться отказом и сохранить исходные байты.
   Проверки записи и удаления проводить только на тестовом ключе после
   разрешения владельца.
4. Проверить отмену и повтор. Повтор делает новый PUT с новым ключом.
   При потере ответа после фактической записи может остаться тестовый объект.
   Очистку выполняет владелец средствами Object Storage.
5. Повторить на Android и iOS. Фактическая сборка Capacitor, её origin и
   воспроизведение требуют отдельной проверки на устройствах.

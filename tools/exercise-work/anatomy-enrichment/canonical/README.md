# База 2: канонические карточки (подготовка)

Источник — фиксированные 1 173 карточки assets/work + результаты PR #845. Запустить генератор после получения ветки с consolidated-index.json:

```
node tools/exercise-work/anatomy-enrichment/canonical/build.mjs
```

Он создаёт fitnessprogramer-canonical.json с полными исходными карточками, исправленным оборудованием, категориями и предложениями по анатомии. Параллельно отмечает непроверенные категории, неизвестные мышцы и отсутствующие переводы.

**Не публиковать этот файл напрямую в Dexie Cloud.** Текущая опубликованная База 2 защищена фиксированным source/release hash. Оператор V1 отклонит изменённые данные по тем же ID. Для замены понадобится отдельный проверяемый сценарий обновления данных / версионирования выпуска, без изменения Blob-объектов GIF и без обнуления программ и тренировок.

В текущих исходных JSON инструкции — `how_to` (EN) и иногда `how_to_ru` (RU), а не `description_ru`. Канонический `description` всегда русскоязычный (или пустой с признаком `missing_russian_description`). Английский текст сохраняется только в `description_en`. Отсутствующий русский перевод нельзя заменять английским без согласованной локализации.
